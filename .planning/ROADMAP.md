# Roadmap: Compás a compás

## Overview

Compás a compás es una aplicación existente, implementada y publicada (versión 0.10.1). Este roadmap registra de forma retroactiva el único hito entregado, **v0.10.1**, que ya está completo: las Fases 0–5 del [plan original](../docs/PLAN.md) y los incrementos posteriores 0.2.0–0.10.1. No hay fases pendientes, planificadas ni futuras ni tareas por ejecutar. Un nuevo alcance se define con `/gsd-new-milestone` cuando el usuario lo decida.

## Milestones

- ✅ **v0.10.1 Aplicación publicada** - Fases 0–5 + Incrementos 0.2.0–0.10.1 (completado; evidencia en [docs/ESTADO.md](../docs/ESTADO.md) y [CHANGELOG.md](../CHANGELOG.md))

**Phase Numbering:**
- Integer phases (0, 1, 2…): trabajo planificado del hito, con la numeración del plan original.
- «Incrementos 0.2.0–0.10.1» no es una fase numerada: agrupa las versiones posteriores a la primera aplicación utilizable.

- [x] **Fase 0: Arranque y propuesta visual** - Estructura del proyecto, comandos reales y primera pantalla con icono, datos de ejemplo y diseño adaptable
- [x] **Fase 1: Estado, compases y edición** - Modelo, validación, CRUD y orden de compases, varios acordes y voicings, entrada por lista y guardado/apertura mínimos
- [x] **Fase 2: Mástil y tarjetas** - Geometría de seis cuerdas, trastes variables, cejuela, cuerdas al aire y mudas, textos y grados manuales
- [x] **Fase 3: Estructura de partitura** - Repeticiones, casillas, Segno, Coda, Fine y saltos con destinos por ID, sin reproducción
- [x] **Fase 4: Paginación y exportación** - Renderizador compartido, hojas A4 apaisadas, `actual/total`, HTML autónomo e impresión a PDF
- [x] **Fase 5: Cierre y documentación de uso** - Validación, documentación de uso, versión visible y `CHANGELOG.md`
- [x] **Incrementos 0.2.0–0.10.1** - Evolución posterior: tarjetas independientes, edición estructural de compases, hoja de ejemplo, filas compactas y saltos de línea

Detalle completo de las fases: [milestones/v0.10.1-ROADMAP.md](milestones/v0.10.1-ROADMAP.md).
